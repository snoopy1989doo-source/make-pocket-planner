# 🐿️ MAKE Pocket Planner

เว็บแอปพลิเคชันช่วยคำนวณ วางแผน และกระจายเงินเดือน 2 รอบต่อเดือน (รอบวันที่ 10 และ 25) รวมถึงเงินพิเศษ (Special Income) เข้าสู่ Cloud Pockets ของ MAKE by KBank ตามโครงสร้าง 5 หมวดหมู่หลัก (Squirrel, Rhino, Cat, Bee, Shark)

---

## 🌟 ฟีเจอร์หลัก (Features)

- **🐿️ 5 Main Categories & 18+ Cloud Pockets:**
  - **Squirrel (🐿️):** `1Life` (ค่ากินจำเป็น), `Fix Cost` (ค่าบ้าน, ค่าเน็ต, ค่าน้ำ, ค่าไฟ)
  - **Rhino (🦏):** `Redwing` (กยศ.), `Debt` (จ่ายหนี้)
  - **Cat (🐱):** `My Babe` (กิจกรรม/เดทกับแฟน), `Joy Full` (Shopping ชิ้นเล็ก)
  - **Bee (🐝):** `Zero 1-5`, `Next Gen`, `Dividend Yield`, `Thai Dividend`, `Cool Money`, `Ruby`
  - **Shark (🦈):** `Life`, `Copy Trade`, `Risk`, `Option`, `Crypto`, `Bot Trade`
- **🗓️ 3 Allocation Modes:** รอบวันที่ 10, รอบวันที่ 25, และเงินพิเศษ (Special Income)
- **⚡ MAKE Companion Transfer Checklist:** โหมดช่วยโอนเงิน พร้อมปุ่ม Copy ตัวเลขยอดเงิน 1 คลิก และ Checklist ติ๊กถูกเมื่อโอนเสร็จ
- **⚙️ Custom Pocket Manager:** ปรับแต่งสัดส่วน % หรือยอด Fix Cost เพิ่ม/ลบกระเป๋าได้อิสระ
- **📜 History & Backup:** บันทึกประวัติการจัดสรร และมีปุ่ม Export/Import ข้อมูล JSON

## 🚀 วิธีการติดตั้งและรัน (Getting Started)

```bash
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd make-pocket-planner

# Install dependencies
npm install

# Start development server
npm run dev
```

---

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Effects:** Canvas Confetti
- **Storage:** LocalStorage (Privacy & Local-First)
